# Брошюры сетей

Сюда кладутся разборы брошюр в формате v1 (30 колонок, тот же, что в Media Radar / навык brochure-offers):
`ГГГГ-ММ-ДД_Сеть_название.csv`, например `2026-11-05_Billa_cw45.csv`.

- **Только открытые источники** (сайты сетей, kimbino, Flipp и т. п.): репозиторий публичный, файлы видны всем.
- `brochures.mjs` (шаг «Брошюры сетей» в workflow `prices`, 2 раза в день) собирает `brochures.json`:
  действующие предложения и те, что начнутся в ближайшие 7 дней. Истёкшие строки отбрасываются сами,
  старые файлы можно удалять раз в месяц.
- Сети: Kaufland, Lidl, Billa, Fantastico, T Market, Metro. Новую сеть добавить в `CHAINS` в `brochures.mjs`
  (название в брошюре → как она называется в данных КЗП).
- Сравнение с ценами КЗП (подсказка в «Спестяване») — только для строк с `kzp_group`, понятной фасовкой,
  без условий (1+1, от суммы, код) и без пометки в колонке `check`.

Проверить локально: `cd data-pipeline && node brochures.mjs --out /tmp/site`.
