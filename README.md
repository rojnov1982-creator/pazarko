# Пазарко (Pazarko) — най-евтината кошница

Самая выгодная потребительская корзина в Болгарии. Интерфейс на болгарском и английском.

Мобильное приложение (React Native / Expo SDK 57), которое по ежедневным ценам супермаркетов
подсказывает, **в каких магазинах что купить**, чтобы корзина вышла дешевле всего, и сравнивает
это с покупкой всей корзины **в одном магазине**.

```
pazarko/
├── data-pipeline/     Node-скрипт: kolkostruva.bg → компактные JSON для приложения
├── app/               Мобильное приложение Expo (iOS, Android, web)
└── .github/workflows/ Ежедневное обновление цен и публикация на GitHub Pages
```

## Откуда цены

С 30.09.2025 Комиссия за защита на потребителите публикует на **kolkostruva.bg** ежедневные цены
по 101 группе товаров «большой потребительской корзины». Сети с оборотом свыше 10 млн лв. обязаны
передавать данные. Открытые данные: `https://kolkostruva.bg/opendata_files/ГГГГ-ММ-ДД.zip`
(архив дня D выходит в D+1 около 00:01, на портале хранится ~14 дней). Внутри — CSV на каждую сеть:

| Населено място (ЕКАТТЕ) | Търговски обект | Наименование | Код | Категория (1–101) | Цена на дребно | Цена в промоция |

Цены в евро. Акционная цена уже есть в данных — отдельный парсинг брошюр для MVP не нужен.

## Быстрый старт

```bash
# 1. Данные
cd data-pipeline
npm install
node ingest.mjs                    # вчерашний день → data-pipeline/out/
node ingest.mjs --date 2026-10-09  # конкретная дата

# 2. Приложение
cd ../app
npm install
npx expo start        # QR-код → Expo Go на телефоне
npm test              # тесты алгоритма корзины
```

**Пошаговый запуск с живыми ценами — [SETUP.md](SETUP.md).** Тестовые сборки и публикация — [TESTING.md](TESTING.md), тексты для сторов — [STORE_LISTING.md](STORE_LISTING.md).

По умолчанию приложение работает на **встроенных демо-данных** (вымышленные сети, 3 города).
Чтобы включить реальные цены, выложите папку `out/` на любой статический хостинг и впишите адрес
в `app/app.json → expo.extra.dataUrl`. Проще всего — workflow `.github/workflows/prices.yml`:
он каждый день скачивает архив и публикует JSON на GitHub Pages.

## Как работает алгоритм

`app/src/lib/optimize.ts`:

1. Для каждого товара корзины и каждой сети берётся минимальная цена в городе
   (с акцией или без — переключатель в настройках).
2. Перебираются все наборы из ≤ K сетей (K = 1, 2, 3 или «любое»), в каждом наборе товар
   покупается там, где дешевле. Выигрывает набор с наименьшим числом ненайденных товаров, затем —
   с наименьшей суммой плюс «цена лишнего магазина» (настройка, чтобы план не дробился ради копеек).
3. Результат сравнивается с покупкой всего в каждой сети; переплата считается на тех товарах,
   что в этой сети есть.

Корректность проверена тестом против полного перебора назначений (40 случайных корзин × K × акции).

## Языки

Болгарский и английский (`app/src/lib/i18n.ts`). Язык берётся из настроек телефона (bg → болгарский,
en → английский, остальные → болгарский) и переключается в «Настройках». Названия товаров тоже
переводятся; названия конкретных продуктов в сетях остаются как в данных КЗП.

## Экраны

- **Кошница / Basket** — город, товары с количеством, готовые корзины («Неделя на семью», «Завтраки», «Барбекю»).
- **Продукти / Products** — 85 групп продуктов и бытовой химии (лекарства скрыты), поиск, «от X €».
- **Спестяване / Savings** — итог, экономия, разбивка «что где купить», сравнение с каждой сетью.
- **Настройки / Settings** — язык, акции, цена лишнего магазина, исключение сетей, информация о данных.

## Как обрабатываются данные КЗП

- **Разные фасовки.** В группах вида «Сирене пакетирано 200 г – 1 кг» размер берётся из названия
  товара, и цена пересчитывается на эталонную фасовку (например 400 г). В группах «1 л», «1 кг»
  бутылка 500 мл пересчитывается на литр. Товары без распознанного размера в диапазонных группах
  не участвуют в сравнении (`data-pipeline/lib/sizes.mjs`).
- **Тип сети.** Аптеки, дрогерии, duty free и строймаркеты помечаются и по умолчанию не участвуют в расчёте.
- **Одна марка — несколько фирм** (два «ФАНТАСТИКО») объединяются в одну сеть.
- **Ошибки в архиве.** Если файл одной сети содержит копию данных другой (так было 09.10.2026:
  в файле «Кауфланд» лежали магазины «Лили Дрогерие»), копия пропускается с предупреждением.
- **Аномальные цены** (в 4+ раза выше/ниже медианы по стране) отбрасываются.

## Марки и супер оферти

- **Марки** (`data-pipeline/lib/brands.mjs`) — словарь марок для молока, кисело мляко, сирене, кашкавала,
  масла, курицы (цяло пиле, филе, бут), кренвиршей, колбас, олио, кофе и пива с вариантами написания
  (Верея / VEREYA). Отдельно — **собственные марки сетей** (Clever/BILLA, Акцент в CBA, Aro/Metro Chef,
  K-Classic; у Lidl — товары без указанной марки): в приложении это вариант «Собствена марка». В приложении у товара можно выбрать
  марку — тогда план считается только по ней. Добавить марку — одна строка в словаре.
- **Супер оферти** — топ-40 скидок дня в каждом городе (20–70%, больше — почти всегда ошибка в данных),
  вкладка «Оферти». Если у товара выбрана марка, а другая марка по акции дешевле минимум на 20%,
  в плане появляется подсказка «Супер оферта» с кнопкой «Вземи тази».

## Premium

Список платных функций — `app/src/lib/premium.ts`. Пока в `app/app.json` → `expo.extra.premiumEnabled`
стоит `false`, всё открыто для всех. Если поставить `true`, без подписки план ограничен 2 магазинами,
выбор марки закрыт замком, а кнопки ведут на экран Premium (сейчас — «Скоро»). Покупки подключаются
позже (например, RevenueCat): после оплаты выставить `settings.isPremium = true`.

## Ограничения и что дальше

- Цена — минимум по сети в городе; в отдельном магазине может отличаться. Дальше — геолокация и
  ближайшие магазины.
- Сети иногда относят товар не к той группе (например, консервированные томаты к «свежим помидорам»).
  Следующий шаг — фильтр по ключевым словам названия для каждой группы.
- Только 101 группа из перечня КЗП. Для остальных товаров — данные брошюр (например, API Price Barometer).

Разбор CSV и словарь групп адаптированы из проекта electionsbg (MIT).
