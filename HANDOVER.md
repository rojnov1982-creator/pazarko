## 1. Что это

Мобильное приложение «Пазарко — най-евтината кошница»: по ежедневным ценам супермаркетов из открытых данных КЗП
подсказывает, в каких магазинах что купить, чтобы корзина вышла дешевле всего, и сравнивает с покупкой всего в
одном магазине. Интерфейс на болгарском и английском.

## 3. Данные

**Источник.** С 30.09.2025 КЗП публикует на kolkostruva.bg ежедневные цены по 101 группе товаров «большой
потребительской корзины» (сети с оборотом свыше 10 млн лв.). `https://kolkostruva.bg/opendata_files/ГГГГ-ММ-ДД.zip`,
архив дня D выходит в D+1 около 00:01, на портале хранится ~14 дней. Цены в евро; промо-цена уже в данных.

Один день (замер 04.11.2026): ZIP 20 МБ, распакованный 169 МБ, 67 CSV (по сети), ~1,08 млн строк, ~1300 магазинов в
252 населённых пунктах. Крупнейшие файлы: Billa, Kaufland, Lidl, Lilly Drogerie, DM.

**Обработка (`ingest.mjs`)**, ежедневно:
- пробует вчера, если нет — 2, 3, 4 дня назад;
- фасовки: размер из названия, пересчёт на эталонную фасовку (`lib/sizes.mjs`); без размера в диапазонных группах — не сравнивается;
- аптеки, дрогерии, duty free, строймаркеты помечаются и по умолчанию не участвуют;
- одна марка — несколько фирм (два «ФАНТАСТИКО») — одна сеть;
- файл сети с копией данных другой сети пропускается (было 09.10.2026: в файле Kaufland лежали магазины Lilly);
- цены в 4+ раза выше/ниже медианы по стране отбрасываются;
- марки (`lib/brands.mjs`): молоко, кисело мляко, сирене, кашкавал, масло, курица, кренвирши, колбасы, олио, кофе,
  пиво, с вариантами написания; собственные марки сетей (Clever/BILLA, Акцент/CBA, Aro/Metro Chef, K-Classic; у Lidl —
  товары без марки) = «Собствена марка»;
- выход: `index.json`, `city/<ЕКАТТЕ>.json` (минимальная цена каждой сети по товару: обычная и промо),
  `city/<ЕКАТТЕ>/s/<id>.json` (цены магазина), «Супер оферти» — топ-40 скидок дня по городу (20–70%).

**Координаты (`geocode.mjs`)**: Nominatim, не чаще 1 запроса в секунду, до 700 за запуск, каждый адрес один раз,
результат коммитится в `data-pipeline/geo/` (автокоммиты «Координаты магазинов [skip ci]»).

## 4. Приложение

**Экраны:** Кошница (город, товары с количеством, готовые корзины «Неделя на семью», «Завтраки», «Барбекю»);
Продукти (85 групп продуктов и бытовой химии, лекарства скрыты, поиск, «от X €»); Оферти (супер оферти);
Спестяване (итог, экономия, что где купить, сравнение с каждой сетью); Настройки (язык, акции, цена лишнего магазина,
исключение сетей, о данных).

**Алгоритм (`src/lib/optimize.ts`):** для товара и сети — минимальная цена в городе (с акцией или без); перебор всех
наборов из ≤ K сетей (K = 1, 2, 3, любое), в наборе товар берётся где дешевле; побеждает набор с наименьшим числом
ненайденных товаров, затем с наименьшей суммой плюс «цена лишнего магазина». Сравнение с покупкой всего в одной сети.
Проверено тестом против полного перебора (40 случайных корзин × K × акции).

**Район покупок:** весь город; «Моите магазини» (до 25 магазинов, их собственные цены); «Близо до» (1–5 км от GPS или
квартала). GPS — только на устройстве.

**Марки:** у товара можно выбрать марку, план считается по ней; подсказка «Супер оферта» с кнопкой «Вземи тази», если
другая марка по акции дешевле на 20%+.

**Данные в приложении:** скачивает `index.json` и файл города, кэш 3 часа (с версией данных: после обновления цен
сразу берёт новые файлы), работает офлайн на последних ценах. Без `dataUrl` — демо-режим с жёлтой плашкой.

**Premium (`src/lib/premium.ts`):** при `premiumEnabled: true` без подписки план ограничен 2 магазинами, выбор марки
закрыт, кнопки ведут на экран Premium («Скоро»). Покупки не подключены (план: RevenueCat, затем `settings.isPremium = true`).

**Аналитика (`src/lib/analytics.ts`, с 06.11.2026):** анонимная статистика в PostHog (EU), только по согласию
(карточка на главном экране при первом запуске + переключатель «Настройки → Поверителност»). Без нативных модулей:
очередь событий и `fetch` на `/batch/`. Включается ключом `expo.extra.analytics.key` (пустой — статистика выключена,
карточка не показывается). События: `app_open`, `$screen`, `city_selected`, `item_added`, `preset_loaded`,
`brand_selected`, `area_changed`, `setting_changed`, `chain_excluded`/`chain_included`, `deal_added`, `superdeal_taken`,
`plan_viewed` (вериги в плане, сумма, экономия, лучшая одна сеть, подсказки брошюр), `brochure_added`, `brochure_chain_filter`. Без GPS, адресов и персональных профилей
(`$process_person_profile: false`, `$geoip_disable: true`).

**Бесплатно:** приложение бесплатное (`premiumEnabled: false`); карточка Premium в настройках скрыта, пока флаг выключен.
Модель дохода — реклама и партнёрства (спонсорские марки/предложения с пометкой «Партньор», не влияющие на расчёт).

**Брошюры (с 06.11.2026):** `data-pipeline/brochures/*.csv` (формат v1) → `brochures.mjs` (шаг workflow `prices`) →
`brochures.json` на GitHub Pages: действующие предложения + начинающиеся в ближайшие 7 дней, цена за эталонную фасовку
группы КЗП (`rp`) там, где фасовка понятна и нет условий. В приложении: «Оферти» → «Брошури» (поиск, фильтр по сети,
«Храни и напитки», срок, «с карта», условие, «+ Добави» для групп КЗП) и подсказка «📰 В брошурата на …» в «Спестяване»,
если брошюра на 5–60% дешевле цены в плане (`src/lib/brochures.ts`, `src/BrochureList.tsx`). Сети брошюр сопоставляются
с сетями КЗП по названию (КАУФЛАНД, ЛИДЛ, БИЛЛА, ФАНТАСТИКО, Т МАРКЕТ, МЕТРО); если в городе ни одна не нашлась —
показываются все. Пополнение — раз в неделю новые CSV в `data-pipeline/brochures/` (см. README там).

**Лесен режим (с 06.11.2026, для пожилых):** выбор при первом запуске («Лесно — едри букви» / «Пълно») и переключатель
в Настройках (`settings.easy`). В нём: всё на 20% крупнее (`useS()`/`useK()` в `src/ui.tsx`), вкладка «Оферти» скрыта,
в корзине нет марок и района, «Спестяване» — общая сумма, экономия одной фразой и «В <сеть> купете: …» по магазинам,
в Настройках только режим, язык и приватность. Значки — свой у каждого товара (`PRODUCT_EMOJI`), не у раздела.

**Варианты 2 и 3 (с 06.11.2026):** `optimizeBasket` хранит 3 лучших плана с разным набором реально использованных сетей
(`result.alternatives`, до 2 штук, по возрастанию цены, в пределах лимита магазинов). В «Спестяване» (оба режима) —
«Други варианти»: сумма, магазины, «с X € по-скъпо», список раскрывается по нажатию (событие `option_opened`).

**Metro по умолчанию не участвует (с 06.11.2026):** это магазин для фирм с клиентской картой. `settings.includeMetro`
(по умолчанию `false`) → `excludedEiks` в store (исключённые в настройках + сети, где `isMetro()` по названию МЕТРО/METRO);
все экраны и брошюры берут `st.excludedEiks`. Переключатель «Metro (нужна е карта)» в Настройках → Изчисление; строка
Metro в «Вериги в града» управляет тем же флагом.

**UX и механика (PR #1, слит в main 06.11.2026):**
- Корзина по ключам (`itemKey`: `g:<группа>` / `pin:<id>`); закреплённые предложения (`BasketItem.pin`, `src/lib/pins.ts`) —
  конкретная акция брошюры или «Супер оферта» КЗП: план берёт её сеть и цену; истёкшая / будущая / сети нет в районе —
  не подменяется, «Разреши замяна» или «Махни». Брошюры получили устойчивый `i` (sha1).
- Цена покупки (`purchase()` в `optimize.ts`): целые упаковки × цена упаковки (до 20% меньше нужного — одна упаковка),
  весовые — по весу; размер не распознан → `approx` («≈ ориентировъчно»). Пайплайн: для стандартных фасовок (`FIXED_GROUPS`)
  цена пачки пишется, только если размер распознан; `products.json` получил `std`.
- `usePlan()` — один расчёт для корзины (предварительная сумма «Ориентировъчно · N от M продукта») и «План».
- Район строго: `areaStatus` loading/ready/partial/empty/error; весь город — только кнопкой; после смены города старые
  данные не используются (`city.ekatte === ekatte`). Состояние данных: дата цен, город/район, сохранённые данные (`isStale`),
  ошибка с повтором (`reload`).
- Навигация: вкладки в `src/app/(tabs)/` (Кошница · Продукти · Оферти · План, Ionicons), настройки — `src/app/settings.tsx`
  поверх (Stack), шестерёнка в заголовке каждого экрана. «План»: сумма/полнота/магазины → варианты → экономия и база →
  список покупок → сравнение (полные/неполные раздельно). ESLint (`npm run lint`).
- Новый вид по концепту пользователя (4 экрана: «Моята кошница», «Продукти», «Оферти за теб», «Твоят план»):
  общий заголовок `AppHeader` (логотип · город/квартал · шестерёнка), палитра `#F6F2EA`/белые карточки/зелёный `#1E6B3F`,
  компоненты `ProductTile`, `ChainBadge`, `Segmented`, `OfferCard`, `Pill` в `src/components.tsx`. Фото товаров заменены
  emoji-плитками (в данных фото нет), логотипы сетей — цветной точкой с названием (товарные знаки не используем).
  Сетки (каталог, варианты плана) — явными рядами, не процентами (на узком экране ряд переполнялся).
- Режим покупок (п. 9): «Започни пазаруване» в «План» сохраняет снимок плана (`ShoppingList` в store, AsyncStorage) →
  `src/app/shopping.tsx`: отметки по магазинам, прогресс, «Остават ≈ X» (итог плана минус купленное), «Приключи».

## 5. Как работать с кодом

```bash
cd data-pipeline && npm install && node ingest.mjs            # вчера → out/
node ingest.mjs --date 2026-10-09 | --zip ~/Downloads/2026-10-09.zip
cd ../app && npm install && npx expo start                     # Expo Go по QR
npm test                                                       # тесты алгоритма
npx tsc --noEmit && npx expo lint                              # до сдачи любой задачи
```

Правила из `app/AGENTS.md`: Expo меняется с каждой SDK — сверяться с документацией v58 (`docs.expo.dev/versions/v58.0.0/`,
`docs.expo.dev/llms.txt`), пакеты ставить через `npx expo install`, навигация только Expo Router, папки `ios/` и
`android/` не создавать руками (настройка через `app.json` и config plugins), нативные библиотеки требуют development
build. В репозитории нет ключей и личных данных — так и должно оставаться (он публичный).
