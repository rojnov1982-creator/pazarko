# Где тестировать Пазарко до публикации

Приложение проходит четыре ступени. Ни на одной из них оно не видно обычным пользователям в сторе.

## 1. Expo Go — на своём телефоне за 2 минуты (бесплатно)

Для разработки и быстрых проверок.

```bash
cd app
npm install
npx expo start
```

Установите **Expo Go** из App Store или Google Play и отсканируйте QR-код (на iPhone — камерой).
Приложение запускается прямо с вашего компьютера; каждое изменение кода видно сразу.
Телефон и компьютер должны быть в одной Wi‑Fi сети (или `npx expo start --tunnel`).

Ограничение: это не «настоящая» установка — без своей иконки, только пока запущен компьютер.

## 2. Тестовая сборка по ссылке — друзьям и коллегам (бесплатно в EAS)

```bash
npm install -g eas-cli
eas login                 # бесплатный аккаунт на expo.dev
eas build --profile preview --platform android
```

- **Android:** EAS даёт ссылку и QR-код на `.apk`. Тестер открывает ссылку и устанавливает
  (нужно разрешить «установку из неизвестных источников»). Аккаунт Google Play не нужен.
- **iPhone:** `eas build --profile preview --platform ios` — нужен Apple Developer (99 $/год).
  Устройства тестеров регистрируются командой `eas device:create` (до 100 iPhone в год).
  Для iPhone удобнее сразу ступень 3.

## 3. Официальные тест-треки сторов

### iPhone — TestFlight
```bash
eas build --profile production --platform ios
eas submit --platform ios
```
В App Store Connect → TestFlight:
- **внутренние тестеры** (до 100 человек из вашей команды) — сразу, без проверки Apple;
- **внешние тестеры** (до 10 000) — по ссылке-приглашению, после короткой бета-проверки (обычно до суток).

Тестер ставит приложение **TestFlight** и устанавливает Пазарко по приглашению.

### Android — тестирование в Google Play
```bash
eas build --profile production --platform android
eas submit --platform android     # загрузит во «Внутреннее тестирование» как черновик
```
В Play Console:
- **Внутреннее тестирование** — до 100 тестеров по e-mail, доступно через несколько минут;
- **Закрытое тестирование** — именно оно нужно для правила новых личных аккаунтов:
  **не меньше 12 тестеров, которые не отключаются 14 дней подряд**. Только после этого
  появится кнопка «Запросить доступ к рабочей версии».

Тестеры получают ссылку, нажимают «Стать тестером» и устанавливают приложение из Google Play —
но в общем поиске его ещё нет.

> Первую загрузку в Google Play иногда приходится сделать вручную (загрузить `.aab` в Play Console),
> после этого `eas submit` работает автоматически. Для автоматической отправки нужен
> ключ сервисного аккаунта Google — см. документацию EAS Submit.

## 4. Публикация

- **App Store:** в App Store Connect выбрать сборку → «Отправить на проверку». Обычно 1–3 дня.
- **Google Play:** после 14 дней закрытого теста — запросить рабочую версию, ответить на анкету
  о тестировании, затем выпустить в «Рабочую версию». Проверка — от нескольких часов до нескольких дней.

## Что подготовить до шага 3

- Политика конфиденциальности (URL) — обязательна в обоих сторах.
- Скриншоты на болгарском и английском (iPhone 6,9″/6,5″, Android телефон).
- Описание и ключевые слова на двух языках.
- Включить реальные данные (`expo.extra.dataUrl` в `app/app.json`) — демо-данные в сторе отклонят.
- Анкеты: App Privacy (Apple), Data safety и возрастной рейтинг (Google).
