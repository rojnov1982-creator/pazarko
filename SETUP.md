# Пазарко: от архива до живых цен — пошагово

Итог: цены будут сами обновляться **дважды в день** и бесплатно публиковаться на GitHub Pages,
а приложение будет брать их оттуда. Вам ничего не нужно запускать вручную.

```
kolkostruva.bg ──(каждый день)──► GitHub Actions ──► GitHub Pages ──► приложение Пазарко
  архив КЗП (ZIP)                  ingest.mjs          index.json,       скачивает цены
                                                       city/*.json,      и кэширует
                                                       privacy.html
```

Время: около 30–40 минут один раз.

---

## Шаг 1. Распаковать архив

Распакуйте `pazarko.zip`, например в `Документы/pazarko`. Внутри:

| Папка / файл | Что это |
|---|---|
| `app/` | мобильное приложение |
| `data-pipeline/` | скрипт, который превращает архив КЗП в данные для приложения |
| `site-static/` | сайт: главная страница и политика конфиденциальности |
| `.github/workflows/prices.yml` | расписание автообновления (папка `.github` может быть скрыта — на Mac покажите её клавишами `Cmd+Shift+.`) |

## Шаг 2. Установить программы (один раз)

1. **Node.js** версии LTS — https://nodejs.org (кнопка «LTS», установить с настройками по умолчанию).
2. **GitHub Desktop** — https://desktop.github.com (проще всего, без командной строки).
3. Аккаунт на **github.com** (бесплатный).

Проверка: откройте Терминал (Mac) или PowerShell (Windows) и выполните `node -v` — должна появиться версия, например `v22…`.

## Шаг 3. Проверить на реальных ценах у себя на компьютере

В Терминале / PowerShell:

```bash
cd Документы/pazarko/data-pipeline      # путь к вашей папке
npm install
node ingest.mjs
```

Скрипт сам скачает вчерашний архив с kolkostruva.bg. В конце должно быть примерно:

```
CSV-файлов: 150+, строк: 1 000 000+, ошибок разбора: 0
Городов: 200+. → …/data-pipeline/out
Топ городов: гр. София (…), гр. Пловдив (…), …
```

**Если вы уже скачали архив вручную** (файл вида `2026-10-09.zip`):

```bash
node ingest.mjs --zip ~/Downloads/2026-10-09.zip
```

(на Windows: `node ingest.mjs --zip C:\Users\ВашеИмя\Downloads\2026-10-09.zip`)

Если что-то пошло не так — пришлите мне текст из окна, разберёмся.

## Шаг 4. Заполнить контакты в политике конфиденциальности

Откройте в любом текстовом редакторе и замените заглушки:

- `site-static/privacy.html` — `[ИМЕ ИЛИ ФИРМА]`, `[NAME OR COMPANY]`, `[EMAIL]` (3 места)
- `site-static/index.html` — `[EMAIL]`

Совет: заведите отдельную почту, например `pazarko.app@gmail.com` — она будет публичной.

## Шаг 5. Загрузить проект на GitHub

1. Откройте **GitHub Desktop** → войдите в аккаунт.
2. **File → Add local repository** → выберите папку `pazarko` → появится предложение
   «create a repository» → нажмите его → **Create repository**.
3. Нажмите **Publish repository**.
   - Name: `pazarko`
   - Снимите галочку **Keep this code private** — бесплатный GitHub Pages работает для публичных репозиториев.
     (В коде нет паролей и личных данных; приватный репозиторий с Pages требует платного плана.)
4. Нажмите **Publish**.

## Шаг 6. Включить GitHub Pages

На github.com откройте свой репозиторий:

**Settings → Pages → Build and deployment → Source: GitHub Actions**

## Шаг 7. Первый запуск обновления

1. Вкладка **Actions** → слева **prices** → справа **Run workflow** → **Run workflow**.
2. Через 2–4 минуты должна появиться зелёная галочка ✅.
3. Откройте `https://ВАШ-ЛОГИН.github.io/pazarko/` — увидите страницу Пазарко со строкой
   «Последни цени: 2026-10-…».
4. Проверьте данные: `https://ВАШ-ЛОГИН.github.io/pazarko/index.json`.

С этого момента обновление идёт **само каждый день в 07:15 и 16:15** по Софии.
Если запуск упадёт, GitHub пришлёт письмо на вашу почту.

## Шаг 8. Подключить приложение к живым ценам

Откройте `app/app.json`, найдите блок `extra` и впишите адрес:

```json
"extra": {
  "dataUrl": "https://ВАШ-ЛОГИН.github.io/pazarko"
}
```

Сохраните. (Вместо правки файла можно задать адрес переменной окружения `EXPO_PUBLIC_DATA_URL`.) В GitHub Desktop: внизу слева напишите «Подключить живые цены» → **Commit to main** → **Push origin**.

## Шаг 9. Запустить приложение на телефоне

```bash
cd Документы/pazarko/app
npm install
npx expo start
```

На телефоне установите **Expo Go**, отсканируйте QR-код. Жёлтая плашка «Демо режим» исчезнет,
появятся настоящие города и сети. Выберите свой город → готовую корзину → «Намери изгодата».

Дальше — тестовые сборки и публикация в сторах: см. `TESTING.md`, тексты — `STORE_LISTING.md`.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| `node: command not found` | Node.js не установлен или нужно перезапустить Терминал |
| `Не удалось скачать архив` | Архив за вчера ещё не вышел (выходит после полуночи) — запустите позже или укажите `--date ГГГГ-ММ-ДД`. Портал хранит только ~14 последних дней |
| В Actions ошибка на шаге «Скачать и обработать цены» | Откройте лог шага и пришлите мне. Если kolkostruva.bg блокирует серверы GitHub — запасной вариант ниже |
| Страница `github.io` показывает 404 | Проверьте шаг 6 (Source: GitHub Actions) и что запуск в Actions зелёный |
| В приложении всё ещё демо | Проверьте `dataUrl` в `app/app.json` (без `/` в конце) и перезапустите `npx expo start` |
| Цены в приложении не обновились | Приложение кэширует цены на 3 часа — подождите или очистите данные приложения |

### Запасной вариант: обновление с вашего компьютера

Если серверы GitHub не могут скачать архив, можно запускать `node ingest.mjs` на своём компьютере
по расписанию (Планировщик заданий в Windows / `cron` или Automator на Mac) и загружать папку `out`
на любой хостинг. Скажите — подготовлю готовый скрипт под вашу систему.

## Как это устроено внутри

1. `prices.yml` запускается по расписанию на серверах GitHub (бесплатно для публичных репозиториев).
2. `ingest.mjs` пробует скачать архив за вчера (если его нет — за позавчера и т.д.),
   разбирает CSV всех сетей, отбрасывает явные ошибки (цена в 4+ раза выше/ниже медианы)
   и для каждого города сохраняет минимальную цену каждой сети по каждому товару — обычную и по акции.
3. Результат вместе с сайтом публикуется на GitHub Pages.
4. Приложение при запуске скачивает `index.json` и файл своего города, кэширует их на 3 часа
   и работает без интернета на последних скачанных ценах.
